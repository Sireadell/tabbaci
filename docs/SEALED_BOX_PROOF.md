# Sealed-box proofs

Each ruling is produced inside a sealed box (a secure chip). The chip signs a statement of what ran, on what input, with what result. The signed proof for a round is saved in this repo under `proofs/<contract>/round-<id>.bundle.json`, so anyone can re-check it offline: `outlayer-verify bundle proofs/court5/round-6.bundle.json --offline`, or let the one-command checker in `tools/verify` do it. It needs no network and no OutLayer service, only the saved file. Round 6 on court5 and rounds 2 and 3 on finalenc1 are included. No bundle is saved yet for finalenc2 rounds; add `--tx <attempt transaction hash> --save-proof` to the checker once `outlayer-verify` is installed.
