Check it yourself

Don't take our word for it. Check it yourself.

These checks are for people who want proof. If you only want to know what happened, you can skip this part. Pick a case and press the button. Your own browser fetches that case from the public record and runs each check itself, one line at a time.

    Your browser checks that the three judges really gave these answers, and that the locked box ran unchanged. That box is a locked box inside a computer chip made by Intel, that nobody can open. It also checks that nobody, including me, can change the first court's rules.

    For developers: check from a command line

    The browser uses Intel's certificates from the saved proof file served with this site, plus the program fingerprint and the approved machine list read live from the public record. Cases 20, 25, 33, 35 and 36 on the first court, and cases 4 to 7 on the second court, pass every line in the browser. Other cases have no saved proof, so a few lines need a developer's computer.     How it works
    What happens to a sentence
    
  
      
    
    1. A writer puts money on it. They pick one word for how sure they are (is, very likely, likely or disputed), and the court holds their money until it decides.
      2. 
    
    2. A locked court reads the evidence. Three AI judges read the evidence and decide, inside a locked box nobody can open, not even me. The box is part of a computer chip made by Intel. It fetches two web pages itself, from a short approved list.
      3. 
    
    3. Three AI judges answer. Each one sees the sentence only as quoted text. So if someone hides an order in it, the judges read the order and don't follow it. Each judge signs its answer, so anyone can check it really came from that judge.

    Honest limits
    What this is not
    
  
    
    
    Not a prediction market.
    The number beside each sentence shows how sure the writer said they were, and how much money they put on it. Nobody trades it.
    
    
    Real money is live on NEAR mainnet.
    Three bonded cases ran on mainnet with real NEAR. That court still has one admin key, so I can fix it if something breaks. Every other case used test tokens on a test network, and each of those case pages says Testnet at the top.
    
    
    Not open to any source.
    The court only reads pages from an approved list of 11, and I control that list. One of them is my own test page, which leaves the list on 16 November.
    
    
    Not a swarm or a live market.
    Both are on my roadmap. Neither is built, and nothing on this site claims them.
